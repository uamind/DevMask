# WebUI 管理界面

DevMask 提供现代化的 Web 管理界面，可以直接在 WeaveMask / KernelSU / APatch 等 root 管理器的模块页面中打开，不必手改 TOML。

## 打开方式

安装模块后，在模块管理器中找到 **DevMask**，点击「WebUI」或「设置」入口即可打开。

::: info 兼容说明
WebUI 采用纯 KernelSU WebUI API 实现，支持 KernelSU、WeaveMask 和 APatch 等兼容 API 的 root 管理器的模块 WebUI 入口。
:::

## 界面结构

底部固定五个导航项，顺序是 **概览 / 模板 / 应用 / 网络 / 设置**，也可以在页面之间左右滑动切换。主题默认跟随系统，浅色与深色是同一套骨架换令牌。

| 页面 | 主要功能 |
|------|---------|
| **概览** | 设备信息、已配置应用数量、四个指标（模板数 / 出口 / 模块版本 / 最近保存）、常用模板、最近改动 |
| **模板** | 机型模板的创建、编辑、删除、搜索、在线模板库、导入导出、批量挂包名 |
| **应用** | 已安装应用列表，按「已配置 / 全部 / 系统应用」筛选并搜索，编辑单个应用的伪装配置 |
| **网络** | 设备整体出口：出口状态、代理定义、出口探测、本机中继，以及常驻的「一键直连」 |
| **设置** | 外观（主题与语言）、高级（模块设置 / 工具 / 外部访问 / 服务状态）、关于 |

## 概览页

- **页头**：原生服务模式下显示设备的制造商与型号、Android 版本；管理器模式下用一句话说明当前环境能做什么
- **主视觉**：当前已配置的应用数量，加两个入口 —— 「管理应用」跳到应用页，「新建模板」跳到模板页
- **四个指标**：模板数、出口状态（已连接 / 直连 / 未启用）、模块版本、最近保存时间
- **常用模板**：按套用应用数取前 3 套，卡片标题优先市场名、其次型号、最后才退回模板名；只有市场名与型号同时存在时才显示型号副标题，卡片里的「N 个应用」是该模板挂的包名数。右上「全部 N 套 →」进模板页。只剩模板名时标题单行省略，不会把卡片撑破
- **最近改动**：配置保存时间与出口连接状态；没有可显示记录时给一句空状态提示

## 应用管理

### 应用列表与筛选

- 列出设备上已安装的应用，并显示其当前是否已配置伪装
- 页头右侧显示已配置数 / 总数，统计的是全部可见应用，不随搜索与筛选变化
- 三段胶囊筛选：**已配置** / **全部**（默认）/ **系统应用**，各自带计数（系统应用的计数在读取完成前不显示）—— 想给系统应用也配伪装就切到「系统应用」
- 支持按应用名或包名搜索，搜索与胶囊筛选叠加生效

### 多用户与多开应用

同一应用的多用户实例（例如 `com.foo` 和 `com.foo@999`）按**实例**去重展示：`com.foo` 与 `com.foo@0` 是同一个实例，列表里不会再出现两行。

- 只靠回退命中主应用配置的分身，显示蓝色**「继承自主应用」**徽标，而不是「已配置」，避免误以为分身有自己的配置
- 配置对话框会标明生效范围：仅主应用（user 0）／主应用 + 所有分身（回退）／仅分身 user N
- 只想让主应用生效、不让分身继承时写 `com.foo@0`；想让主应用和所有分身都生效时写裸包名 `com.foo`
- 列表底部另有「分身与继承」说明卡，只在确实存在跟随主应用的分身时出现，并给出分身数量

### 编辑应用配置

点击某个应用进入配置编辑：

- 直接填写各字段（制造商、品牌、型号、设备代号等）
- 选择已存在的[机型模板](./configuration/index.md#方式一机型模板)快速套用
- 设置 `companion_resetprop`、`force_denylist_unmount`、`dpi` 等开关
- 在 `custom_props` 区域添加自定义属性

### 给应用套用模板

在应用编辑页选择「应用模板」，即可把某个模板的所有字段一次性填充进来，再按需微调。

## 模板管理

### 页头与搜索

页头第一行是标题「机型模板」、「N 套」计数与主操作「新建模板」；第二行是搜索框加「在线模板」「导入/导出」两个入口。模板卡只展示三样东西 —— 模板名、型号代码（`model` / `device` / `product`，都没有时显示「未填写型号」）、套用应用数，其余字段都在编辑弹窗里。

### 创建与编辑模板

- 填写机型字段，保存为命名模板
- 模板创建后可在多个应用间复用

### 批量应用到包名

编辑模板时，在 `packages` 列表中添加包名。保存后，这些包名会自动使用该模板。

::: warning 一个包名只挂一个模板
同一个包名被多个模板声明时，运行时只认 `config.toml` 里**书写靠前**的那个模板。模板页会出现一行「包名重复配置 N」的告警条，默认收起，点开才逐条列出哪个模板生效、哪个被忽略；合并模板时请先去重包名。
:::

### 导入 / 导出

- **导出**：勾选要导出的模板（可多选），生成 TOML 文本，一键复制
- **导入**：粘贴 TOML 文本导入模板
- **读取本机**：直接 `getprop` 读取当前设备属性并生成模板，可保存为模板或复制文本

### 在线模板库

WebUI 内置在线模板源，可以从社区模板仓库筛选后一键导入：

- 仓库地址：[uamind/devmask-config](https://github.com/uamind/devmask-config)（DevMask 维护）
- 打开后先显示数据源与详情拉取进度，支持刷新与失败重试
- 分类胶囊（全部 / 通用设备 / 游戏设备 / 破限设备）与品牌胶囊叠加筛选
- 支持按品牌、型号、模板名或**模板描述**搜索；多个关键词以空白分隔，需全部命中
- 点任意一行打开预览抽屉，确认 fingerprint、作者、版本与描述后再导入；返回键先关抽屉，再关模板库

::: tip 欢迎贡献
如果你有整理好的机型配置，可以提交到 `uamind/devmask-config`，帮助更多用户。
:::

### 重命名已存在模板

模板支持重命名，重命名后所有引用该模板的应用配置会自动更新。

## 网络页

网络页是设备端出口的**唯一**配置入口（设置页只留一张入口卡）。页头状态卡与「一键直连」按钮常驻，下面依次是代理定义、探测结果与本机中继三张卡。

### 出口状态与一键直连

- 状态胶囊：**已连接** / **直连** / **未启用**；fail-open 生效时追加「已降级为直连」，读回不一致时追加「未生效（读回不一致）」
- 状态卡给出期望模式、生效模式、系统代理是否生效、settings 读回、`egress revision`、`egress.toml`、凭据状态与最近探测，右上「刷新」重新拉取
- **一键直连**：无论当前什么状态，页头右上都有这个按钮；点按二次确认后清空系统代理并回落直连

### 代理定义

- 每条定义显示名字、协议（HTTP / SOCKS5 等）、`host:port`、凭据是否已设置，以及实际链路（经设备内中继 `127.0.0.1:端口`、直连上游，或凭据未生效）
- 右上「编辑」打出口定义弹窗：启用设备级代理、类型、主机与端口、用户名与密码（可清空已存凭据）
- 弹窗的「高级」组里是探测地址、超时、fail-open 与探测目标

### 探测结果（出口 IP）

- 卡片顶部显示当前探测目标，点「编辑」直达高级组
- 「探测出口 IP」给出出口 IP、延迟、链路、探测时间、上游状态与作用范围；若出口被判定为近似值会额外标注并给出提示
- 当前环境不支持探测时按钮置灰并说明原因

### 本机中继

- 显示中继是否启用、基础端口、fail-open、并发上限、uid 防火墙状态与监听列表（哪个代理在听哪个端口）
- 「重启中继」只在服务支持时可用；中继端口发生变化后，卡片会列出需要重启的应用
- 带凭据的代理由设备内中继持有：应用只连 `127.0.0.1:端口`，凭据不会写进应用配置

## 设置页

设置页分**外观 / 高级 / 关于**三组，中间插一张「网络出口」入口卡。

### 外观

- **主题**：跟随系统（默认）/ 浅色 / 深色
- **语言**：跟随系统 / 简体中文 / English / Türkçe

### 网络出口入口

一整行可点的入口卡，点按跳到网络页；出口的表单、探测与中继都不在设置页里重复。

### 高级

- **模块设置**：调试模式（对应 `config.toml` 的 `debug`，开启后日志文件才会有 Info 级记录）；下方常驻日志路径 `/data/adb/devmask/logs/devmask.log`，可一键复制
- **工具 → 配置转换**：选一个其它机型伪装模块的 zip，WebUI 在 WebView 内解析其中的 `system.prop` 并转成模板（不落盘、不调用命令行工具），确认预览内容后「保存为模板」。从旧模块迁移过来时用它
- **外部访问**：允许局域网内其它设备访问 WebUI，可设端口与访问 Token，并显示绑定地址、状态与局域网地址；保存并重启服务、重置为默认 Token、刷新状态
- **服务状态**（卡头「服务」）：当前传输（管理器模式 / 原生服务模式 / 只读）、服务版本、绑定地址、配置 revision、最后修改、Token 是否已设置、作用域；可刷新状态、设置 Token、退出登录

::: tip 只读环境
连不上原生服务时（`/api/v1/healthz` 不可达），页面进入只读：外部访问卡隐藏，服务状态只保留能读到的字段与「刷新状态」，写操作按钮全部收起。
:::

## 手势与导航

- **侧滑返回逐级导航**：在多层页面（应用 → 编辑 → 字段详情、模板库 → 预览抽屉）之间侧滑可返回上一级
- **左右滑动切换页面**：在底部五个 Tab 之间可以通过滑动快速切换
- **返回键**：在线模板库与预览抽屉接入了历史记录，返回键先关抽屉、再关模板库、最后才离开模板页

## 多语言

WebUI 界面支持多语言切换，目前支持：

- 简体中文
- English
- Türkçe

语言设置与系统语言默认保持一致，也可在 WebUI 设置页手动切换。土耳其语下页面标题会按屏幕宽度收窄字号（≤384px 用 16px），360dp 下仍为单行；≤320dp 的极窄屏仍可能换行。
